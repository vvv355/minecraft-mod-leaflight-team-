\# LuminousLeaves (Светящийся лист)



Декоративный мод для Minecraft, добавляющий светящийся блок листвы.



\## Совместимость

\- Minecraft: 1.21.1

\- Fabric Loader: 0.20.1+

\- Fabric API: 0.107.0+



\## Установка

1\. Установите Fabric Loader и Fabric API.

2\. Поместите файл `luminous-leaves-1.0.0.jar` в папку `mods`.

3\. Запустите игру.



\## Крафт

Для создания блока потребуется 8 дубовых листьев и 1 светопыль (по схеме 3х3).
